Game Overview

WITTYZ is a competitive quiz-race game where players answer multiple-choice questions by running between stations to scan QR codes. The game can be played in two modes: TEAMS or SINGLE PLAYERS.

Game Modes

Teams Mode

  • Set up 2-12 teams with 1-20 players per team
  • Questions are divided equally among team players
  • Each player answers their assigned questions
  • Team score is cumulative from all players
  • Highest scoring team wins!

Single Players Mode

  • 1-50 individual players compete
  • Each player answers the same 20 questions
  • Highest individual score wins!

Creating Your Quiz

Step 1: Download the Quiz Excel Template (button above)
Step 2: Fill in your questions following this format:
  • Column A: Question text
  • Column B: Answer 1
  • Column C: Answer 2
  • Column D: Answer 3
  • Column E: Answer 4
  • Column F: Correct answer number (1-4)
Step 3: Upload your Excel file to the Dashboard
💡 Tip: You can also use the "Create Quiz with AI" feature to generate questions automatically!

🎲 How to Play

Starting the Game

  1. Sign in to the app
  2. Select your quiz from the library
  3. Choose game mode (Teams or Single Players)
  4. Configure number of teams/players
  5. Start the game!

During Gameplay

  1. Read the Question: Question appears on screen with 4 colored answer boxes
  2. Scan QR Code: Use the scanner at the top to scan the QR code of your chosen answer
  3. Get Feedback: Answer box turns yellow, then shows "GOOD" (green) or "WRONG" (red)
  4. Move On: Game automatically advances to next question
⚠️ Important: QR codes must match the current question number. Scanning the wrong question shows a warning!

🏆 Scoring System

  • Starting Score: Total questions × 60 points
  • Timer Penalty: -1 point per second
  • Wrong Answer: -20 points penalty
  • Final Score: Remaining points when all questions are answered

🎨 Answer Box Colors

  • 🔴 Red Box: Answer 1
  • 🔵 Blue Box: Answer 2
  • 🟢 Green Box: Answer 3
  • 🟡 Yellow Box: Answer 4

🔐 Game Controls

  • Pause/Resume: Requires Face ID authentication (freezes timer)
  • Cancel: Requires Face ID authentication (exits game)
🔒 Security: Face ID protection prevents kids from pausing or canceling games without permission!

📱 QR Code Requirements

  • Hold device steady for 1 second
  • QR code must be at least 160×160 pixels on screen
  • Ensure good lighting for best scanning

🎵 Sound Effects

  • Background Music: Plays throughout the game
  • Beep Sound: Countdown and wrong question warnings
  • End Tune: Celebratory sound when team finishes

✨ Tips for Best Experience

  1. Print QR codes clearly on quality paper
  2. Organize QR codes by question number
  3. Test your quiz before the game
  4. Ensure good lighting for QR scanning
  5. Set up Face ID before starting games
