How to Play WITTYZ

Game Overview

WITTYZ is a quiz game that combines trivia with physical activity. Players race between question stations set up around a space, and they have to scan a QR code at each station to submit their answer. Each station can only be scanned once, and each QR code represents one of the possible answers. Because players must physically reach the correct station to answer, the game rewards both speed and knowledge. 

An organizer is needed to set up each game, who may or may not participate as a player. See the following sections for details.

Ways to Play

A Single Shared Device or Multi-Device Play

The game organizer can set up a game played with a single mobile device that is passed between players, or a multi-device game where players join, each with their own device.

Game Modes

Teams Mode

  • 2-12 teams with 1-20 players per team can play
  • Questions are divided equally among team players
  • Each player answers their assigned questions
  • Team score is cumulative from all players
  • Highest scoring team wins!

Single Players Mode

  • 1-50 individual players compete
  • Each player answers the same 20 questions
  • Highest individual score wins!

Preparing for the Game

  • The organizer selects the answer stations locations where the QR codes will be displayed.
  • Print the QR code signs on paper then mount on a piece of wood or cardboard, or create permanent signs by sending the file to a sign printing company to be printed on corrugated plastic.
  • The signs can then be secured into the ground using wood or wire stakes.

Starting the Game

The organizer will need to choose between single device or multi-device play. The steps for both are almost identical:   

  1. Sign in to the app
  2. Select your quiz from the library
  3. Choose game mode (Teams or Single Players)
  4. Configure number of teams/players
  5. For multi-device play, click "Next: Place Signs". You will then be able to scan each sign and the app mark their locations on the map displayed on the screen
  6. For multi-device play, the last step is to generate the game code that the organizer will share with the player so they can join the game
  7. The game can now start!

During Gameplay

  1. Read the Question: Question appears on screen with 4 colored answer boxes
  2. Scan QR Code: Use the scanner at the top to scan the QR code of your chosen answer
  3. Move On: Game automatically advances to next question
⚠️ Important: A QR Code sign can only be scanned once. Scanning a sign more than once triggers a warning!

Scoring System

  • Starting Score: Total questions × 60 points
  • Timer Penalty: -1 point per second
  • Wrong Answer: -20 points penalty
  • Final Score: Remaining points when all questions are answered

Answer Box Colors

  • Red Box: Answer 1
  • Blue Box: Answer 2
  • Green Box: Answer 3
  • Yellow Box: Answer 4

Game Controls

  • Pause/Resume: Requires Face ID authentication (freezes timer)
  • Cancel: Requires Face ID authentication (exits game)
Security: Face ID protection prevents kids from pausing or canceling games without permission!

QR Code Requirements

  • Hold device steady for 1 second
  • Ensure good lighting for best scanning

Tips for Best Experience

  1. Print QR codes clearly on quality paper
  2. Test your quiz before the game
  3. Ensure good lighting for QR scanning
  4. Set up Face ID before starting games
